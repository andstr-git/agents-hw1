# Краткий отчёт

## Результат

Мини-трекер реализован автономно, без OpenSpec, папки `openspec/`, CDN, внешних
библиотек и API-ключей.

Файлы:

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка интерфейса, подписи полей и кнопок, офлайн-подключение стилей и модуля |
| `styles.css` | Адаптивная тема без внешних ресурсов, мобильная раскладка от 390 px |
| `domain.mjs` | Чистые расчёты, фильтрация, операции над списком и валидация ввода |
| `app.mjs` | DOM, события, отрисовка, сохранение в `localStorage` с безопасным откатом |
| `tests/acceptance.test.mjs` | Автотесты T1–T5 на `node:test` + проверка офлайн-структуры |

Исходные правила и ожидаемые значения не изменялись: часы 0,5–24 с шагом 0,5,
прогресс по часам, исходный пример 8/2/25%, после «Практики» — 6/8 и 75%,
фильтр не меняет базу расчёта.

## Проверки

Запуск:

```powershell
node --test tests/acceptance.test.mjs
```

Фактический результат: **6 тестов, 6 пройдено, 0 ошибок**.

Покрыто:

- **T1** — 3 исходные задачи, 8 ч всего, 2 ч выполнено, 25% именно по часам.
- **T2** — переключение «Практики» даёт 6/8 ч и 75%; исходный массив не мутируется.
- **T3** — фильтр «активные» показывает только «Практику» и «Повторение», общий
  прогресс остаётся 25%.
- **T4** — пустое название, пробелы, пустые, отрицательные и нечисловые часы,
  границы 0,5/24, шаг 0,5 и запятая как разделитель; при ошибке `value === null`,
  введённые значения возвращаются без изменений.
- **T5** — после удаления всех задач 0 ч, 0%, все значения конечны (без
  `NaN`/`Infinity`).
- Дополнительно — `index.html` использует только локальные `styles.css` и
  `app.mjs`, поля связаны с `label`, есть подписи у фильтров и внешних ресурсов
  нет.

Также выполнена проверка синтаксиса: `node --check app.mjs` и
`node --check domain.mjs`.

## Ручные проверки интерфейса

Браузер в рамках этой работы **не запускался**, поэтому перечисленные ниже
проверки предложены и ещё не выполнены:

1. Открыть страницу с чистым `localStorage`: видны 3 задачи, «Всего 8 ч»,
   «Выполнено 2 ч», прогресс 25%.
2. Отметить «Практику»: чекбокс и зачёркивание меняются в интерфейсе,
   показатели становятся 6 ч и 75%.
3. Переключить «Активные»: в списке только «Практика» и «Повторение»,
   сводка по-прежнему 8 ч / 2 ч / 25%; «Готовые» показывает только «Чтение».
4. Отправить пустое название, одни пробелы, пустые часы, `-1`, `0`, `24,5`,
   `1,25`, `abc`: задача не добавляется, ошибка видна рядом с полем, введённые
   значения остаются в форме.
5. Проверить границы: `0,5` и `24` добавляются, `0,25` и `24,5` отклоняются;
   `2,5` добавляется.
6. Удалить все задачи: 0 ч, 0%, сообщение о пустом состоянии, в цифрах нет
   `NaN`/`Infinity`, добавление новой задачи продолжает работать.
7. Ширина 390 px: нет горизонтального скролла, текст переносится, поля и
   кнопки читаемы и имеют подписи.
8. Клавиатура: Tab проходит по чекбоксам, фильтрам, полям и кнопкам; у полей с
   ошибкой есть `aria-invalid`, сообщения объявляются через `role="alert"`.
9. Перезагрузить страницу: задачи и отметки сохраняются.
10. Заблокировать `localStorage` (например, в DevTools) или открыть в режиме без
    хранилища: появляется понятное предупреждение, работа продолжается в памяти.
11. Нажать «Сбросить к исходному примеру»: возвращаются 3 задачи, 8 ч, 2 ч, 25%.

## Запуск интерфейса

Из-за ES-модулей браузер может блокировать `file://`. Для ручной проверки нужен
локальный HTTP-сервер, например:

```powershell
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`.
