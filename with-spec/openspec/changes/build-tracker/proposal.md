# Proposal

## Why

Нужен учебный мини-трекер задач на неделю, который можно открыть локально без сборки, CDN, внешних библиотек и API-ключей. Он должен честно считать прогресс по часам, а не по количеству задач, и оставаться работоспособным на узком экране 390 px.

## What Changes

- Добавляется автономное статическое приложение из `index.html`, `styles.css`, `app.mjs`, `domain.mjs`.
- Появляется доменный слой `domain.mjs` с чистыми функциями валидации, добавления, удаления, переключения `done` и расчёта прогресса по часам.
- Реализуется интерфейс: список задач, форма добавления, удаление, переключение статуса, фильтр «все / активные / готовые», сводка по часам и прогрессу.
- Валидация формы: непустое название после `trim`, часы от 0,5 до 24 с шагом 0,5; некорректный ввод не добавляет задачу, показывает ошибку рядом с полем и сохраняет введённые значения.
- Прогресс считается по всем задачам независимо от активного фильтра: `round(100 × часы done / часы всех)`, при пустом списке — 0 % без `NaN`/`Infinity`.
- Добавляется приёмочный тест `tests/acceptance.test.mjs`, покрывающий сценарии T1–T5.
- Опциональное улучшение из брифа принимается в объём: сохранение задач в `localStorage` с понятным сообщением и продолжением работы в памяти при недоступном хранилище.

## Capabilities

### New Capabilities

- `tracker`: управление списком учебных задач, валидация ввода, фильтрация, расчёт итоговых часов и прогресса, пустое состояние и адаптивный интерфейс.

### Modified Capabilities

Нет: проект создаётся с нуля, существующие спецификации отсутствуют.

## Impact

- Новые файлы в корне проекта: `index.html`, `styles.css`, `app.mjs`, `domain.mjs`.
- Новый тест: `tests/acceptance.test.mjs` (запуск встроенным `node --test`, без внешних зависимостей).
- Внешние зависимости, сетевые запросы и API-ключи не добавляются.
- Опционально затрагивается браузерное хранилище `localStorage`; при его недоступности приложение обязано остаться работоспособным в памяти.
